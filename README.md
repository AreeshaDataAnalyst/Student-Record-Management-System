# 🎓 Student Record Management System

A simple and beginner-friendly **Student Record Management System** developed using **Python** and **File Handling** concepts.
This project allows users to store, manage, search, and display student records using a text file.

---

# 🚀 Features

✅ Add Student Records
✅ View All Students
✅ Search Student by Name
✅ Automatic Grade Calculation
✅ Display Total Number of Students
✅ Clear All Records
✅ Menu-Driven Program
✅ File Handling using `students.txt`

---

# 📂 Technologies Used

* Python
* File Handling
* Functions
* Loops
* Conditional Statements
* Exception Handling

---

# 📋 Functionalities

## 1️⃣ Add Student

Users can add:

* Student Name
* Roll Number
* Marks

The data is automatically stored in:

```txt id="u2v5tg"
students.txt
```

Example:

```txt id="q5vplr"
Ali,101,88
Sara,102,91
```

---

## 2️⃣ View All Students

Displays all student records in a clean format:

```txt id="d9r5lv"
Name: areesha | Roll No: 1002 | Marks: 89 | Grade: A
```

---

## 3️⃣ Search Student

Users can search for any student by name.
If the student exists, the complete record is displayed.

---

## 4️⃣ Grade System

| Marks    | Grade |
| -------- | ----- |
| 80+      | A     |
| 70–79    | B     |
| 60–69    | C     |
| Below 60 | Fail  |

---

## 5️⃣ Clear Records

Allows users to remove all student records from the file.
